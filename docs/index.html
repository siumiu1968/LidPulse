LidPulse

Give your MacBook Pro lid light a job.

Control the illuminated Apple logo on a supported MacBook Pro. Keep it steady, set a breathing effect, follow the music you play, or see when Codex and Claude Code are busy or need you.

Four ways to use the Apple logo light

Steady

Set the brightness of the Apple logo independently of the screen.

Breathe

Fade the logo up and down at a pace you choose.

Music

Pulse along with music playing on your Mac. Set the intensity or go dark between beats.

Agents

See when Codex or Claude Code is working, idle, or waiting for your attention.

Install on a supported Mac

LidPulse needs an Apple silicon Mac with a physically illuminated lid logo. It has been tested on a PROLED XDR MacBook Pro (Mac17,10) running macOS 27.2.

Open the DMG, drag LidPulse into Applications, then open it. Find the glowing Apple logo in the menu bar. Use Settings to switch languages, open at login, or connect an agent.

Use Keep Lit With Screen Off or Lid Closed in the menu bar panel to keep applying your effect while the Mac stays awake. The lid light turns off during system sleep.

This release is ad hoc signed and has not been notarized by Apple. macOS may block a downloaded copy at first launch.

Full brightness, audio and agent permissions

On a Mac with brightness limits, choose Unlock Full Brightness to have macOS request administrator approval. You can restore the previous limits in Settings. The app does not ask for admin approval when it starts.

Music mode requests system audio access. Audio is analyzed locally and is not saved or uploaded. For Codex, review and trust the installed hooks in Codex Settings before using the agent light.

MacBook 機蓋 Apple Logo 燈控制

LidPulse 係一個選單列 App，可以調較機蓋 Logo 亮度，設定長亮、呼吸或音樂節拍，亦可以顯示 Codex 同 Claude Code 狀態。支援有實體發光 Logo 嘅 Apple silicon Mac。

獨立設定有繁體中文及英文介面、登入啟動、AI 連接及最高亮度選項。如果部機仍有限制，你可以按「解除最高亮度限制」，由 macOS 要求管理員授權，之後亦可以還原。
